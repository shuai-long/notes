## 计算多个时间的实际时长

```abap
types: begin of ty_tims,
         beguz type tims,
         enduz type tims,
       end of ty_tims,
       tt_tims type table of ty_tims with default key.
       
class-methods merging_time
  importing
            it_times         type tt_tims
  returning value(rv_result) type anz5_4.
```

```abap
method merging_time.

  data(lt_tims) = it_times.
  data: lt_tims_final type tt_tims.

  sort lt_tims by beguz.
  read table lt_tims into data(ls_time_merged) index 1.
  loop at lt_tims into data(ls_time_current) from 2.
    if ls_time_current-beguz <= ls_time_merged-enduz.
      if ls_time_current-enduz > ls_time_merged-enduz.
        ls_time_merged-enduz = ls_time_current-enduz.
      endif.
    else.
      append ls_time_merged to lt_tims_final.
      ls_time_merged = ls_time_current.
    endif.
  endloop.

  append ls_time_merged to lt_tims_final.

  loop at lt_tims_final into ls_time_merged.
    rv_result = rv_result + ( ls_time_merged-enduz - ls_time_merged-beguz ).
  endloop.

  rv_result = rv_result / 3600.

endmethod.
```

## 将小时数转换为时间

```abap
class-methods conv_decimals_to_tims
	importing
		iv_hours type any
		iv_dec   type c default abap_true
	returning value(rv_result) type tims.
```

```abap
methods conv_decimals_to_tims.
  data: lv_total_seconds type p decimals 6,
        lv_hours         type int4,
        lv_minutes       type int4,
        lv_seconds       type int4,
        lv_hours_numc    type n length 2,
        lv_minutes_numc  type n length 2,
        lv_seconds_numc  type n length 2.
  if lv_dec = abap_true.
    lv_total_seconds = iv_hours * 3600. 
  else.
    lv_total_seconds = iv_hours / 10000 * 3600.
  endif.
  lv_hours = lv_total_seconds div 3600.
  lv_minutes = ( lv_total_seconds - ( lv_hours * 3600 ) ) div 60.
  lv_seconds = round( val = lv_total_seconds - ( lv_hours * 3600 ) - ( lv_minutes * 60  ) dec = 0 ).

  if lv_seconds = 60.
    lv_seconds = 0.
    lv_minutes = lv_minutes + 1.
    if lv_minutes = 60.
      lv_minutes = 0.
      lv_hours = lv_hours + 1.
    endif.
  endif.

  lv_hours_numc = lv_hours.
  lv_minutes_numc = lv_minutes.
  lv_seconds_numc = lv_seconds.

  rv_result = |{ lv_hours_numc alpha = in }{ lv_minutes_numc alpha = in }{ lv_seconds_numc alpha = in }|.
endform.
```
