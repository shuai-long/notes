# VA01/VA02/VA03

## 销售订单抬头屏幕增强

### 屏幕增强实现

首先在销售订单抬头表 `VBAK` 中 append 一个自定义结构，用于存放需要增强到抬头屏幕上的字段。

![VBAK 中 APPEND 自定义结构](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-vbak-append.png)

然后通过事务码 `SE80` 打开程序 `SAPMV45A`，进入屏幕 `8309`，直接在该屏幕上放置需要增强的字段，字段名称绑定到 `VBAK` 中追加的自定义字段。

![SAPMV45A 屏幕 8309](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-header-screen-8309.png "image-grid cols=2 min=360 gap=12")
![抬头屏幕字段增强](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-header-layout-field.png)

抬头屏幕增强中，PBO 的 MODULE 放到程序 `MV45AOZZ` 中，PAI 的 MODULE 放到程序 `MV45AIZZ` 中。

### 屏幕增强位置

在销售订单界面中，通过菜单路径 `转到 -> 抬头 -> 附加功能 -> 附加数据B` 进入抬头增强页签，进入后即可看到 SAP 预留的销售订单抬头屏幕增强区域。

![抬头附加数据 B 菜单路径](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-header-menu.png "image-grid cols=2 min=360 gap=12")
![销售订单抬头附加数据 B](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-header-additional-data-b.png)

## 销售订单行项目屏幕增强

### 屏幕增强实现

首先在销售订单行项目表 `VBAP` 中 append 一个自定义结构，用于存放需要增强到行项目屏幕上的字段。

![VBAP 中 APPEND 自定义结构](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-vbap-append.png)

然后通过事务码 `SE80` 打开程序 `SAPMV45A`，进入屏幕 `8459`，直接在该屏幕上放置需要增强的字段，字段名称绑定到 `VBAP` 中追加的自定义字段。

![SAPMV45A 屏幕 8459](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-item-screen-8459.png "image-grid cols=2 min=360 gap=12")
![行项目屏幕字段增强](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-item-layout-field.png)

行项目屏幕增强中，PBO 的 MODULE 放到程序 `MV45AOZZ` 中，PAI 的 MODULE 放到程序 `MV45AIZZ` 中。

### 屏幕增强位置

在销售订单界面中，先选中对应行项目，再通过菜单路径 `转到 -> 项目 -> 更多功能 -> 附加数据B` 进入 SAP 预留的销售订单行项目屏幕增强区域。

![行项目附加数据 B 菜单路径](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/sales-order-va-item-menu.png)
