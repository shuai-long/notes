# FMCIA

### 屏幕增强实现

在表 `FMCI` 中 include 结构 `CI_FMCI`，并加入自定义字段，如下图。

![截图 p231](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p232-01.png)

客户增强 `FMMD0017`：用户定义的承诺项目屏幕字段 (新的)。

将该增强通过事务码 `CMOD` 注册到项目中。

![截图 p232](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p232-02.png)

双击出口进入，操作位置如下图。

![截图 p232](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p232-03.png)

点击红框位置继续进入，操作位置如下图。

![截图 p232](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p232-04.png)

在下图中双击对应程序。

![截图 p232](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p233-01.png)

双击屏幕：0 100，如下图。

![截图 p233](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p233-02.png)

将自定义结构 `CI_FMFCTR` 中的字段放到屏幕里。

![截图 p233](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p233-03.png)

根据输入状态对自定义屏幕中的字段进行输入控制。
