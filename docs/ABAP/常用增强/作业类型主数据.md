# KL01/KL02/KL03

### 屏幕增强实现

客户增强 `COOMLA01`：作业类型主数据的客户字段。

将该增强通过事务码 `CMOD` 注册到项目中。

![截图 p210](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p211-01.png)

如下图双击红框处，创建结构`CI_CSLA`。

![截图 p210](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p211-02.png)

双击出口进入，操作位置如下图。

![截图 p211](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p211-03.png)

点击红框位置继续进入，操作位置如下图。

![截图 p211](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p211-04.png)

在下图中双击对应程序。

![截图 p211](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p212-01.png)

继续双击屏幕 `0999`，如下图。

![截图 p212](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p212-02.png)

将自定义结构 `CI_CSLA` 中的字段放到屏幕里。

![截图 p212](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p212-03.png)

根据输入状态对自定义屏幕中的字段进行输入控制。

![截图 p213](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p213-01.png)
![补充截图 p213-02](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p213-02.png)

出口函数 `EXIT_SAPLKMA6_001`。

![截图 p214](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p214-01.png)

出口函数 `EXIT_SAPLKMA6_002`。
