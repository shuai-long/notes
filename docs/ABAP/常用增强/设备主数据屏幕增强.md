![截图 p180](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p181-03.png)

红框中的参数如下：

![截图 p180](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p182-01.png)

* `I_OBJECT_TYPE` = '02'" '1' = F/L '2' = `EQU` '3' = `SER`

* `I_ACTIVITY_TYPE` = '3' " '1' = Insert '2' = Update '3' = Display

* `I_ACTIVE_FCODE` = ''."Function Code Representing Active Tabstrip

* 编号 描述 F 代码

* 0010 一般的 SD

* 0020 位置 ST

* 0030 组织结构 IH

* 0050 结构 `HIER`

* 0060 附加数据 1 `ZUS1`

* 0100 附加数据 2 `ZUS2`

* 0105 附加数据 3 `ZUS3`

* 0120 其他 `SON`

出口函数 `EXIT_SAPLITO0_002`。

![截图 p181](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p182-02.png)
