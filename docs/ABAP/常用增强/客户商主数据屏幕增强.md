# 客户商主数据屏幕增强

### 屏幕增强实现

根据需求对以下表APPEND 自定义结构（下面以分别对`KNA1`，`KNB1`，`KNVV` 做三个例子）

`KNA1` 客户主文件的一般数据

`KNB1` 客户主数据 (公司代码)

`KNVV` 客户主记录销售数据
