# 项目屏幕增强

### 屏幕增强实现

在表 `PROJ` 中 include 结构 `CI_PROJ`，并加入自定义字段，如下图。

![截图 p133](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p134-01.png)

客户增强 `CNEX0006`：PS 客户指定字段项目定义。

将该增强通过事务码 `CMOD` 注册到项目中。

![截图 p134](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p134-02.png)

双击出口进入，操作位置如下图。

![截图 p134](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p134-03.png)

点击红框位置继续进入，操作位置如下图。

![截图 p134](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p135-01.png)

在下图中双击对应程序。

![截图 p134](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p135-02.png)

INCLUDE 程序 `ZXCN1TOP`。

![截图 p135](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p135-03.png)

继续双击屏幕 `0600`，如下图。

![截图 p135](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p136-01.png)

将自定义结构 `CNCI_PROJ` 中的字段放到屏幕里。

![截图 p135](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p136-02.png)

根据输入状态对自定义屏幕中的字段进行输入控制。

![截图 p136](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p136-03.png)

出口函数 `EXIT_SAPLCJWB_002`。

![截图 p136](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p136-04.png)

出口函数 `EXIT_SAPLCJWB_003`。

![截图 p136](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p137-01.png)
