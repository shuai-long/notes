# 供应商主数据屏幕增强

### 屏幕增强实现

根据需求对以下表APPEND 自定义结构（下面以分别对`LFA1`，`LFB1`，`LFM1` 做三个例子）

`LFA1` 供应商主数据 (一般地区)

`LFB1` 供应商主数据 (公司代码)

`LFM1` 供应商主记录购买组织数据
