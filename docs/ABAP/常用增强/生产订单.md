# CO01/CO02/CO03

## 生产订单抬头屏幕增强

### 屏幕增强实现

在表 `AUFK` 中 include 结构 `CI_AUFK`，并加入自定义字段，如下图。

![截图 p149](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p150-02.png)

客户增强 `PPCO0012`：生产订单：显示/更改订单抬头数据。

将该增强通过事务码 `CMOD` 注册到项目中。

![截图 p150](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p150-03.png)

双击出口进入，操作位置如下图。

![截图 p150](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p151-01.png)

点击红框位置继续进入，操作位置如下图。

![截图 p150](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p151-02.png)

在下图中双击对应程序。

![截图 p150](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p151-03.png)

INCLUDE 程序 `ZXCO1TOP`。

![截图 p151](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p152-01.png)

继续双击屏幕 `0100`，如下图。

![截图 p151](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p152-02.png)

将自定义结构 `COCI_AUFK` 中的字段放到屏幕里。

![截图 p151](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p152-03.png)

根据输入状态对自定义屏幕中的字段进行输入控制。

![截图 p152](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p153-01.png)

出口函数 `EXIT_SAPLCOKO1_001`。

![截图 p152](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p153-02.png)

出口函数 `EXIT_SAPLCOKO1_002`。

![截图 p153](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p153-03.png)
