# CO11N/COOIS

### 屏幕增强实现

在表`AFRU`中用APPEND方式加入自定义字段，如图。

![截图 p271](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p272-01.png)

客户增强 `CONFPP07`：单一屏幕条目: 包含用户定义的子屏幕。

将该增强通过事务码 `CMOD` 注册到项目中。

![截图 p271](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p272-02.png)

双击出口进入，操作位置如下图。

![截图 p271](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p272-03.png)

点击红框位置继续进入，操作位置如下图。

![截图 p271](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p273-01.png)

在下图中双击对应程序。

![截图 p272](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p273-02.png)

双击屏幕：0 910，如下图。

![截图 p272](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p273-03.png)

将自定义结构 `ZAPPEND_AFRU` 中的字段放到屏幕里。

![截图 p273](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p273-04.png)

出口函数 `EXIT_SAPLCORU_S_100`。

![截图 p273](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p274-01.png)

出口函数 `EXIT_SAPLCORU_S_101`。

![截图 p273](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p274-02.png)

做完以上增强开发后，还需要做后台配置对应的屏幕才会在前台显示

可以直接使用事务码 `OPK0`

双击实际业配所使用到的“确认参数文件”，如下图。

![截图 p274](https://picture-bj.oss-cn-beijing.aliyuncs.com/pciture/abap-screen-enhancement-v4-p275-01.png)

在区域中选上“0910自由定义细节屏幕2”，在按钮文件中写入“自定屏幕增强

0910”

注意：

区域中的“0900自由定义细节屏幕1” 对应增强中的屏幕 0900

区域中的“0910自由定义细节屏幕2” 对应增强中的屏幕 0910

区域中的“0920自由定义细节屏幕3” 对应增强中的屏幕 0920

而屏幕 `5900` 5910 5920，本人暂时也不知道在哪里使用到。
