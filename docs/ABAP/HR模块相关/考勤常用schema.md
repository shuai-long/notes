## 读法与索引

- **PE01 函数**安排流程；**PE02 操作**处理 PCR 当前数据。
- PE01 示例按“函数 · 参数1 · 参数2 · 参数3 · 参数4”书写；**— 表示空白，不是输入字符**。
- 字段取值分为固定代码、配置/主数据键、运行时序号、数值/日期；配置值按目标系统解释。
- 同名表里的数量不一定都是小时，例如 9005 为病假天数、9105 为病假时数。

### 符号速查

| 写法 | 在本文中的含义 |
| --- | --- |
| PCR | 人事计算规则，在 PE02 维护；schema 为 PE01 中的计算流程。 |
| `HRS` | 考勤数值工作字段；原始时间通常按小时，但规则换算后也可保存天数等中间值。 |
| `?` | 在 RTE/NUM/AMT/HRS 等运算中表示比较；结果常为 `<`、`=`、`>`。 |
| `*` / `****` | 含义随位置变化：ADDWT 的 `*` 是当前工资项；PCR 入口的 `*` / `****` 可表示通用分组/通用工资项；判断树的 `*` 是通用匹配路径。 |
| `P1`—`P4` | PE01 的四个参数栏；必须按列填写，不能把中间空白省掉后整体左移。 |
| `Z001` | 本文部分例子中的教学规则名；不表示系统已存在该规则。 |

## PE02 操作字典

<a id="hrs"></a>
### HRS

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 赋值／计算／比较 |
| 作用 | 操作当前数值工作字段 ACT-ANZ。 |
| 语法 | `HRS运算符操作数` |
| 参数 / 可用值 | = 赋值；+ 加；- 减；\* 乘；/ 除；? 比较。Dxxxx=TES 当日时间类型；Mxxxx=SALDO 累计时间类型；S=当天计划工时；Cxxxxx=常数。 |
| 结果 | 算术写回 HRS；比较返回 <、=、>。 |
| 例子 | HRS=D9005；HRS=M9005；HRS=S；HRS=0；HRS?8；HRS/S。 |
| 注意 | HRS 不是一张表；修改 HRS 不会自动保存到 TES。换算后可能是天数，不再是小时。 |

<a id="varst"></a>
### VARST

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 属性判断 |
| 作用 | 查询当前日期、工作计划或处理状态，形成判断键。 |
| 语法 | `VARST参数` |
| 参数 / 可用值 | FREE=计划工时是否为 0；HOLCL=节假日类；DAYTY=日类型；DAYPG=日工作计划；DPRCL=日工作计划类；WEDAY=星期；FIRST/LAST=当前 TIP 首/末记录；P2001=缺勤装载状态。 |
| 结果 | FREE/FIRST/LAST/P2001 常为 Y/N；其他返回属性代码。WEDAY：1=周一…7=周日。 |
| 例子 | VARSTFREE：Y=计划工时 0，N=不为 0；VARSTHOLCL：返回 PSP-FTKLA。 |
| 注意 | FREE 不等于周末；FIRST/LAST 不等于月初/月末。 |

<a id="outtp"></a>
### OUTTP

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 时间对字段判断 |
| 作用 | 查询当前 TIP 时间对的字段或关联数据。 |
| 语法 | `OUTTP参数` |
| 参数 / 可用值 | VTYPE=处理类型；PTYPE=时间对类别；TIMDS=ZTYPE；TITYP=ZTART；STAT1=配对状态；ORIGS=来源；CLTYP=VERSL；ABTYP=缺勤类型；PRTYP=出勤类型。 |
| 结果 | 返回该属性的实际代码；取值表见 TIP 字段字典。 |
| 例子 | OUTTPVTYPE：S/M 等；OUTTPPTYPE：0/1/2/3；OUTTPTIMDS：01—10 等。 |
| 注意 | 操作参数名不一定等于字段名：要查 ZTYPE 用 TIMDS，要查 VERSL 用 CLTYP。 |

<a id="outtp-flags"></a>
### OUTTP 的存在性判断

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 真假判断 |
| 作用 | 判断当前时间对是否具有时刻或关联分配。 |
| 语法 | `OUTTPEXTIM 等` |
| 参数 / 可用值 | EXTIM=开始和结束时刻都存在；EXBTM=开始时刻存在；EXETM=结束时刻存在；C1SET=成本分配存在；ALSET=替代支付存在。 |
| 结果 | Y=存在；N=不存在。 |
| 例子 | OUTTPEXTIM：区分有具体时刻的时间对与只有数量的记录。 |
| 注意 | 判断存在性，不比较时长大小。 |

<a id="adddb"></a>
### ADDDB

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 日余额累计／覆盖 |
| 作用 | 将数值写入 TES 的指定时间类型。 |
| 语法 | `ADDDBxxxx[模式]` |
| 参数 / 可用值 | xxxx=4 位时间类型；模式空白=加当前 HRS；Z=覆盖为当前 HRS；-=加当前 HRS 的相反数；T=加入计划工时。 |
| 结果 | 改变 TES-ZTART 对应的 ANZHL。 |
| 例子 | ADDDB9005：累加；ADDDB9005Z：覆盖；HRS=0 后 ADDDB9005Z：将当日值置 0。 |
| 注意 | HRS=0 后只做 ADDDB9005 是加 0，不是清空。 |

### COLOP

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 传递时间对 |

<a id="round"></a>
### ROUND

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 考勤 / 舍入 |
| 作用 | 对时刻或当前数值做指定方向的舍入。 |
| 语法 | `ROUND类型方向间隔` |
| 参数 / 可用值 | 本例 H=当前 HRS；>=向上；<=向下；30=30 分钟间隔。其他 B/E 等形式作用于时刻，另查参数。 |
| 结果 | 舍入后覆盖相应工作值。 |
| 例子 | ROUNDH>30：非负时长按半小时向上，1.1 小时→1.5 小时。 |
| 注意 | 30 不是小数位数；先区分小时小数和 HHMMSS 时刻。 |

<a id="tables"></a>
## 内部表字段字典

**字段清单按本次实际结构展开，包含当前结构中的标准字段；屏幕可能只显示其中一部分。** 这些通常是计算内部表/结果结构，不是可以直接当同名数据库表查询的对象；当前人员、期间通常保存在外层上下文，不在每一行重复。

类型读法：CHAR(n)=n 字符；NUMC(n)=n 位数字字符；DATS(8)=日期；RAW(n)=n 字节关联号；DEC(p,s)/CURR(p,s)=总 p 位、其中 s 位小数。数值字段没有有限的“代码值清单”，应按单位、正负号和业务规则解释。

| 表 / 结构 | 存储的信息 | 字段入口 |
| --- | --- | --- |
| TIP / TOP：PZI01 | 当前日的输入/输出时间对，时刻、类别、来源、关联指针 | [28 个字段](#tab-tip) |
| TES：PZI02 | 当前日时间类型的余额 | [2 个字段](#tab-tes) |
| ZES：PC2B6 | 按日保存的时间类型结果 | [3 个字段](#tab-zes) |
| SALDO：PC2B5 | 按期间累计的时间类型余额 | [2 个字段](#tab-saldo) |
| PSP：PC2BA → PTPSP | 每天的工作计划、日类型、假日类和工时 | [13 个字段](#tab-psp) |
| DZL：PTM_DZL；ZL：PC2BF | 日工作工资项与保存/导出的工资项 | [各 11 个字段](#tab-zl) |
| ZML：PZI08 | 待补偿处理的加班工资项 | [11 个字段](#tab-zml) |
| ERT / FEHLER：PC2B8 | 时间评估错误/消息；当前 PERT 读取 ERT_FOR_RULE | [12 个字段](#tab-ert) |

<a id="tab-tip"></a>
### TIP / TOP — 时间对

| 字段 | 类型 | 存储的信息 | 可用值 / 含义 |
| --- | --- | --- | --- |
| `BEGTM` | CHAR(6) | 开始时刻 | 字符型逻辑时刻，常见 HHMMSS，如 090000；跨日表示可超过 24 小时；空白可表示无具体时刻。 |
| `ENDTM` | CHAR(6) | 结束时刻 | 同 BEGTM；例如 260000 可表示相对当前日的次日 02:00，不能直接当 ABAP TIMS。 |
| `STAT1` | CHAR(1) | 时间对配对状态 | 空白=无错误；其他值见[STAT1 配对状态](#val-pcst1)。 |
| `PTYPE` | CHAR(1) | 时间对类别/出勤状态 | 0=未记录时间/休息；1=工作/出勤；2=已记录或批准的缺勤；3=外勤/手工记录出勤。 |
| `ZTYPE` | CHAR(2) | 相对日工作计划的时间标识 | 01=加班；02=填充时间；03=核心时间等，完整值见[ZTYPE](#val-ztype)。 |
| `CLTIM` | NUMC(2) | 处理类型/时间类型类 | 2 位分组数值，T555Y 的分类键；具体类别含义依配置，不是小时数。 |
| `VTYPE` | CHAR(1) | 时间评估处理类型 | 常见空白、-、S、M、A、P、K；见[VTYPE](#val-vtype)。字段域本身不是固定枚举域。 |
| `ZTART` | CHAR(4) | 时间类型 | 4 字符配置键；T555A/T555B，必须带 MOBDE；如本系统 01/9005=病假天数。 |
| `ANZHL` | DEC(7,4) | 当前时间对小时数 | 数值，4 位小数；如 1.5000=1.5 小时，不是 1 小时 50 分。 |
| `BSART` | CHAR(3) | 开始时间事件类型 | RETYP 代码；如 P10=上班打卡、P15=休息开始；见[事件码](#val-retyp)。 |
| `ESART` | CHAR(3) | 结束时间事件类型 | RETYP 代码；如 P20=下班打卡、P25=休息结束；同事件码字典。 |
| `VERSL` | CHAR(1) | 加班补偿类型 | 配置键，T555R/T555T；本系统 1=计加班费、2=休息时间加上加班率、3=转调休。 |
| `PTZNR` | RAW(2) | 原始配对记录指针 | 运行时序号，关联 PT；初始值=没有关联，不是员工号。 |
| `ALZNR` | RAW(1) | 替代支付指针 | 运行时序号，关联 ALP；初始值=无关联。 |
| `C1ZNR` | RAW(2) | 成本分配指针 | 运行时序号，关联 C1；初始值=无关联。 |
| `PRZNR` | RAW(2) | 出勤记录指针 | 运行时序号，关联出勤记录；初始值=无关联。 |
| `ABZNR` | RAW(1) | 缺勤记录指针 | 运行时序号，关联 AB；初始值=无关联。 |
| `KTZNR` | RAW(1) | 出勤配额指针 | 运行时序号，关联出勤配额；初始值=无关联。 |
| `ORIGS` | CHAR(1) | 时间对来源 | E=时间事件；A=缺勤；P=出勤；O=加班；R=待命；D=计划生成；C=出勤/缺勤原因。 |
| `INTKY` | CHAR(1) | 待命类型内部键 | 配置键，按 V_T557/待命类型配置解释；非统一枚举。 |
| `BGCOD` | CHAR(4) | 开始打卡的出勤/缺勤原因 | 配置键，T705A/T705H 等相关原因定义/文本；不是缺勤天数。 |
| `EGCOD` | CHAR(4) | 结束打卡的出勤/缺勤原因 | 同 BGCOD。 |
| `BTERM` | CHAR(4) | 开始打卡终端 ID | 4 字符终端标识；由终端配置定义。 |
| `ETERM` | CHAR(4) | 结束打卡终端 ID | 4 字符终端标识；由终端配置定义。 |
| `AESTA` | CHAR(1) | 手工修改/录入状态 | 空白=两端来自时间记录系统；1=开始手工录入；2=结束手工录入；3=两端均手工录入。 |
| `SRTFD` | CHAR(2) | 公共排序字段 | 2 字符运行时排序信息，不是固定业务状态。 |
| `VAR01` | CHAR(1) | 任意标志 1 | 1 字符，由规则/程序定义；域无固定业务枚举。 |
| `VAR02` | CHAR(2) | 任意标志 2 | 2 字符，由规则/程序定义；域无固定业务枚举。 |

### ERT / FEHLER — 错误与消息

| 字段 | 类型 | 存储的信息 | 可用值 / 含义 |
| --- | --- | --- | --- |
| `LDATE` | DATS(8) | 消息逻辑日期 | YYYYMMDD，消息所属的处理日。 |
| `LTIME` | TIMS(6) | 消息逻辑时间 | HHMMSS；空/初始表示未给具体时间。 |
| `ERRTY` | CHAR(1) | 消息来源/类别 | 1=COLER 生成；2=旧式配对用户消息（不再使用）；3=配对技术错误；4=时间评估技术错误；5=评估警告/提示。 |
| `ERROR` | CHAR(2) | 消息编号 | 2 字符配置码，查 T555E/T555F；与 ERRTY、相应配置上下文一起解释。 |
| `MESTY` | CHAR(1) | 消息严重程度 | E=错误；A=中止；空白=提示/注释。不是所有消息表都使用这套取值。 |
| `HISTF` | CHAR(1) | 历史记录标志 | 字符标志；域无固定值清单，具体状态由消息生成/历史化逻辑定义，不能与 XFELD 自动等同。 |
| `UTEXT` | CHAR(10) | 消息补充文本 | 最多 10 字符，具体消息的补充值，不是消息全文。 |
| `PDSNR` | NUMC(12) | PDC 消息顺序号 | 12 位数字序号，用于识别消息。 |
| `STATUS` | CHAR(1) | 处理状态 | 空白=新建；1=处理中；2=完成；3=已确认。 |
| `AEDTM` | DATS(8) | 最后处理日期 | YYYYMMDD。 |
| `UNAME` | CHAR(12) | 最后处理用户 | SAP 用户名，最多 12 字符；无固定枚举。 |
| `OPERNR` | NUMC(8) | 消息来源人员号 | 8 位人员号；并行雇佣等情形用于标明来源，不是消息状态。 |


<a id="values"></a>
## 代码值字典

以下同时列固定域值与常用处理约定；后者已明确标注，不能当作固定枚举。配置键须连同分组和有效日期查值；“有这个值”不等于当前方案一定使用它。

<a id="val-ptype"></a>
### PTYPE — 时间对类别

来源：域 PATYP。描述这个时间对属于哪种记录，不表示最终是否发加班费。

| 值 | 含义 |
| --- | --- |
| `0` | 未记录的时间 / 休息 |
| `1` | 工作 / 出勤时间 |
| `2` | 已记录、经批准的缺勤 |
| `3` | 外勤或手工录入的出勤 |

<a id="val-vtype"></a>
### VTYPE — 处理类型

字段本身没有固定域值清单。下列是标准处理约定，由 TIMTP、PCR 等给时间对分类；客户自定义值须追踪上游赋值规则。

| 值 | 含义 |
| --- | --- |
| 空白 | 不计为生产时间 |
| `-` | 待后续删除的时间对 |
| `S` | 计划工作时间 |
| `M` | 加班 |
| `A` | 计入计划时间计算的缺勤 |
| `P` | 计入计划时间计算的出勤 |
| `K` | 核心夜间工作时间 |

例如当前方案中出现 `GWT · — · O · ZML · —`，只能确认它选择 VTYPE=O 的时间对；O 的业务含义还需看该方案如何赋值，不能直接套用其他系统的名称。

<a id="val-ztype"></a>
### ZTYPE — 时间标识 / 与工作计划的关系

来源：域 TPCOD；OUTTP 使用参数 TIMDS 查询本字段。不是四位时间类型 ZTART。

| 值 | 含义 |
| --- | --- |
| `01` | 加班 / 计划外时间 |
| `02` | 填充时间（Fill time） |
| `03` | 核心时间 |
| `04` | 核心时间中的休息 |
| `05` | 填充时间中的休息 |
| `06` | 带薪休息 |
| `07` | IT2005 中的无薪休息 |
| `08` | IT2005 中的带薪休息 |
| `09` | 加班中的休息 |
| `10` | 域列有此代码，但 SAP 标准不支持 |

<a id="val-pcst1"></a>
### TIP-STAT1 — 配对状态

来源：域 PCST1；与薪资 WPBP-STAT1 的人员状态完全不同。

| 值 | 含义 |
| --- | --- |
| 空白 | 时间对无配对错误 |
| `1` | 只有中间打卡 |
| `2` | 缺少上班打卡 |
| `3` | 缺少下班打卡 |
| `4` | 缺少休息结束 |
| `5` | 缺少休息开始 |
| `7` | 缺少外勤开始 |
| `8` | 缺少外勤结束 |
| `A` | 已在时间评估中分割 / 截断时间对 |
| `E` | 缺少订单确认 |

<a id="val-origs"></a>
### ORIGS — 时间对来源

来源：域 ORIGS；回答“从哪里来”，与 PTYPE 的“属于哪类”不同。

| 值 | 含义 |
| --- | --- |
| `E` | 时间事件 / 打卡 |
| `A` | 缺勤 |
| `P` | 出勤 |
| `O` | 加班 |
| `R` | 待命 / 可用性 |
| `D` | 按日工作计划生成 |
| `C` | 出勤 / 缺勤原因 |

<a id="val-tagty"></a>
### TAGTY / FTKLA / TPKLA / VARIA — 工作计划分类

来源：相应域与个人工作计划结构。类号可以决定后续规则选择；类号本身通常不编码固定的付薪比例。

| 字段 | 可用值 | 含义 |
| --- | --- | --- |
| `TAGTY` | 空白 / `0` | 按个人工作计划工作；0 可由系统规范为空白。 |
| `TAGTY` | `1`—`9` | 不同非工作日类别；不可仅凭数字断定有薪或无薪，须结合客户配置。 |
| `FTKLA` | 空白 / `0` | 非公共假日 / 默认类。 |
| `FTKLA` | `1`—`9` | 公共假日类别；全日、半日及计数/计薪处理应查日历与规则。 |
| `TPKLA` | `0`—`9` | 日工作计划分类码；0—9 各自含义由计划设置和引用该值的规则决定。 |
| `VARIA` | 空白 | 标准日工作计划变式。 |
| `VARIA` | `0`—`9`、`A`—`Z` | 可配置的其他变式；需结合 MOTPR、TPROG、生效日期查 T550A。 |

<a id="val-flags"></a>
### AESTA 与布尔标志

AESTA 用于说明时间事件的录入方式；XFELD 型标志才统一按 X/空白解释。不要把所有 CHAR(1) 都当布尔值。

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `AESTA` | 空白 | 开始和结束都来自时间记录系统 |
| `AESTA` | `1` | 开始时间事件为手工录入 |
| `AESTA` | `2` | 结束时间事件为手工录入 |
| `AESTA` | `3` | 开始和结束均手工录入 |
| ACTIV / START_BEF_ZERO 等已核实布尔字段 | `X` | 是；具体“是什么”看对应字段说明 |
| 同上 | 空白 | 否 / 未设置 |

ERT 的 ERRTY、MESTY、STATUS 已在[消息字段表](#tab-ert)逐项展开。HISTF、NAT01/NAT02 等没有核实到统一固定枚举的字段，需沿用其生成程序的定义。

## 核对来源与继续查法

- **本次系统依据**：BAESL_100 的 DD03L/DD04T、固定域及上述配置表；TIP/TOP/TES/DZL/ZML 声明见 RPTDAT20，PSP/ZL 见 RPC2B201，ZES/SALDO/消息结构见 RPC2B202。字段来自 PZI01、PZI02、PC2B5、PC2B6、PC2B8、PC2BF、PTM_DZL、PZI08、PTPSP。
- **关键操作核对**：OUTTP 对照 RPTBU100_OPOUTTP；VARST 对照 RPTBU200_OPVARST；HRS 对照 RPTBU300_OPHRS/VGET；ADDDB、ROUND、GWT、DAYMO、IF、CUMBT、PERT 对照当前标准实现。
- **查参数**：PE04 显示对应函数/操作文档；PE01 区分参数1—4；PE02 区分操作、判断键和续行。少用变体按目标系统文档查，不把英文缩写当业务定义。
- **查字段和值**：SE11 显示结构、数据元素、域固定值/检查表；配置键带上分组、日期和文本语言。字段清单是内部结果结构，不代表存在同名透明数据库表。
