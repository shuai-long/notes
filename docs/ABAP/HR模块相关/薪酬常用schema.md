> 按关键字查“做什么、怎么写、参数有哪些、返回什么”。核对基准：BAESL_100，2026-10-12。
>
> 配套：[考勤 schema 字典](考勤常用schema.md)。

## 读法与索引

- **PE01 函数**：流程中的指令，如 PIT、PITAB、IF；**PE02 操作**：PCR 内的指令，如 CMPER、ADDWT。
- 本文列常用语法；国别专用和少用修饰符不混入主条目。
- PE01 示例按“函数 · 参数1 · 参数2 · 参数3 · 参数4”书写；**— 表示空白，不是输入字符**。
- 字段取值分为：固定代码、配置/主数据键、运行时序号、数值/日期。配置键没有适用于所有系统的固定中文含义，需按表中来源查值。

### 符号速查

| 写法 | 在本文中的含义 |
| --- | --- |
| PCR | 人事计算规则，在 PE02 维护；schema 为 PE01 中的计算流程。 |
| `R` / `N` / `A` | 薪资数值字段：费率 / 数量 / 金额，分别对应 BETPE / ANZHL / BETRG。 |
| `?` | 在 RTE/NUM/AMT/HRS 等运算中表示比较；结果常为 `<`、`=`、`>`。 |
| `*` / `****` | 含义随位置变化：ADDWT 的 `*` 是当前工资项；PCR 入口的 `*` / `****` 可表示通用分组/通用工资项；判断树的 `*` 是通用匹配路径。 |
| `P1`—`P4` | PE01 的四个参数栏；必须按列填写，不能把中间空白省掉后整体左移。 |
| `Z001` | 本文部分例子中的教学规则名；不表示系统已存在该规则。 |

## PE02 操作字典

<a id="cmper"></a>
### CMPER

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 比较 |
| 作用 | 比较当前工资所属期间与指定期间。 |
| 语法 | `CMPER YYPP` |
| 参数 / 可用值 | YY：两位年份；PP：工资期间号。月度核算通常为 01—12，因此可按“年月”读。此处是无 R 修饰符的形式。 |
| 结果 | <：早于；=：相同；>：晚于。 |
| 例子 | CMPER 2606：与 2026 年第 06 期间比较。10 月回算 5 月时返回 <。 |
| 注意 | 比较 APER-PAPER（所属期），不是系统日期或所在期；非月度的 06 不一定是 6 月。 |

<a id="outwp"></a>
### OUTWP

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 取值／判断 |
| 作用 | 查询人员或工作中心属性，将值送入判断分支。 |
| 语法 | `OUTWP查询参数` |
| 参数 / 可用值 | PAYSB=工资范围；PERSG=员工组；PERSB=员工子组；ABART=PCR 分组；COMPY=公司代码；PLANT=人事范围；PLTSC=人事子范围；COSTC=成本中心；SHIFT=工作计划规则。 |
| 结果 | 返回对应代码，例如工资范围 BB；不是 Y/N，也不写 AMT。 |
| 例子 | OUTWPPAYSB：查询 APER-ABKRS；本系统 BB=发放劳务费人员。 |
| 注意 | PAYSB≠PERSB。PERSB 返回 PERSK；ABART 也不是工资范围。 |

<a id="vwtcl"></a>
### VWTCL

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 取值／判断 |
| 作用 | 查询当前工资项的处理类值。 |
| 语法 | `VWTCL nn` |
| 参数 / 可用值 | nn：两位处理类号，例如 01、10。值来自工资项配置 T512W/V_512W_D。 |
| 结果 | 返回该处理类的配置值，例如 0、1；含义必须结合“处理类号＋值”。 |
| 例子 | VWTCL 10：根据处理类 10 的值选择分支。 |
| 注意 | 不是与数字 10 比较，也不是读取第 10 个工资项。 |

<a id="pppar"></a>
### PPPAR

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 条件判断 |
| 作用 | 查询部分期间状态。 |
| 语法 | `PPPAR 参数` |
| 参数 / 可用值 | 常用 E=期内入职/有效计算期开始边界；A=期内离职/结束边界；S=WPBP 分段；U=无薪缺勤；B=有薪缺勤；R=劳动关系暂停等对应状态。 |
| 结果 | 条件成立返回参数字母，如 A；不成立通常返回 \*。 |
| 例子 | PPPAR A：成立走 A 分支，否则走 \* 分支。 |
| 注意 | A/E 还检查计算期边界，不能只按人事事件名称推断。 |

<a id="rte-num-amt"></a>
### RTE／NUM／AMT

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 赋值／运算／比较 |
| 作用 | 分别操作当前记录的费率 R、数量 N、金额 A。 |
| 语法 | `RTE运算符操作数；NUM运算符操作数；AMT运算符操作数` |
| 参数 / 可用值 | 常用 = 赋值、+ 加、- 减、\* 乘、/ 除、? 比较；数字为常数；Kxxxxx 取 T511K 常数；T… 取相应部分期间技术参数。 |
| 结果 | = + - \* / 修改当前字段；? 返回 <、=、>。 |
| 例子 | NUM=1；AMT?0；RTE\*8；RTE=KGENAU；RTE=TSSOLL；RTE/TSDIVP。 |
| 注意 | N 的单位看 ZEINH 和业务规则；R 可以是计算因子。修改工作值后仍要输出。操作数来源及空格位置不可随意改。 |

<a id="multi"></a>
### MULTI

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 乘法 |
| 作用 | 将两个数值字段相乘，结果写入指定字段。 |
| 语法 | `MULTI xyz` |
| 参数 / 可用值 | x、y、z 各为 R/N/A；x=第一个数，y=第二个数，z=结果字段。 |
| 结果 | 写回 z；没有判断分支。 |
| 例子 | MULTI RNA：R×N→A。R=100、N=2 时，A=200。 |
| 注意 | 不会自动 ADDWT。 |

<a id="divid"></a>
### DIVID

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 除法 |
| 作用 | 将两个数值字段相除，结果写入指定字段。 |
| 语法 | `DIVID xyz` |
| 参数 / 可用值 | x、y、z 各为 R/N/A；x=分子，y=分母，z=结果字段。 |
| 结果 | 写回 z。 |
| 例子 | DIVID ANA：A÷N→A。A=200、N=2 时，A=100。 |
| 注意 | 先确认分母和业务单位，尤其是小时、天数、计薪除数。 |

<a id="zero"></a>
### ZERO=

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 清零 |
| 作用 | 清除当前工资项的指定数值字段。 |
| 语法 | `ZERO= 字段组合` |
| 参数 / 可用值 | R=费率；N=数量；A=金额；可组合 RNA、AN 等。另有变量表形式 ZERO=&xxxx。 |
| 结果 | 所选字段变为 0；不自动输出或删除整表。 |
| 例子 | ZERO= RNA：当前 R、N、A 全部清零。 |
| 注意 | 不撤销已 ADDWT 的记录；清零后有无 ADDWT 决定本次路径是否显式输出。 |

<a id="fillf"></a>
### FILLF

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 恢复／复制 |
| 作用 | 从当前输入工资项恢复数值到当前工作记录。 |
| 语法 | `FILLF 字段组合` |
| 参数 / 可用值 | R/N/A 及组合，如 A、RNA。 |
| 结果 | 恢复指定字段，当前规则中之前对这些字段的修改被覆盖。 |
| 例子 | FILLF RNA：恢复输入记录的费率、数量和金额。 |
| 注意 | 不是清零，也不是恢复所有 split。 |

<a id="addwt"></a>
### ADDWT

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 输出／累计 |
| 作用 | 把当前工资项记录写入指定输出表，可改变输出工资项号。 |
| 语法 | `ADDWT目标修饰符工资项` |
| 参数 / 可用值 | 普通空白修饰符→OT；E→RT；I→IT；C→CRT；&→VAR。工资项 \* 表示当前工资项号，1000 等表示指定号。 |
| 结果 | 写入/收集目标记录；相同目标键可能合并。 |
| 例子 | ADDWT \*：原号输出到 OT；ADDWT 1000：以 1000 输出；ADDWTE\*：输出到 RT；ADDWT&Z001：存入变量键 Z001。 |
| 注意 | 在普通 PIT 中，结束路径没有 ADDWT 就没有该次 OT 输出；重复 ADDWT 可能重复累计。不是只复制金额。 |

<a id="elimi"></a>
### ELIMI

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 清除关联标识 |
| 作用 | 清除当前工资项的指定 split，使后续处理不再按该关联区分。 |
| 语法 | `ELIMI split组合` |
| 参数 / 可用值 | A=WPBP；R=PCR 员工子组分组；K=成本分配；T=替代支付；U=银行转账；Y=缺勤；X=变量分配；Z=时间单位；\* 为全部相关 split。 |
| 结果 | 改变关联键；不直接改 R/N/A。 |
| 例子 | ELIMI A：清掉当前记录的 WPBP 关联标识。 |
| 注意 | 不是删除 WPBP 数据，也不是把金额清零。 |

<a id="reset"></a>
### RESET

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 恢复关联标识 |
| 作用 | 恢复被 ELIMI 消除的相应 split。 |
| 语法 | `RESET split组合` |
| 参数 / 可用值 | 使用相应 split 字母，例如 A、R、K 或 \*。 |
| 结果 | 恢复相应关联标识。 |
| 例子 | RESET A：恢复 WPBP split。 |
| 注意 | RESET 中的 A 是 split 类型，不是 AMT 金额。 |

<a id="pcy"></a>
### PCY

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 调用子规则 |
| 作用 | 调用另一个 PCR，处理后返回调用位置。 |
| 语法 | `PCY 规则名` |
| 参数 / 可用值 | 规则名为 PCR 名；分组、通用入口等附加写法要按 PE04 对应变体查看。 |
| 结果 | 子规则完成后继续原规则。 |
| 例子 | PCY Z001：调用名为 Z001 的教学示例 PCR。 |
| 注意 | 它调用 PCR；COPY 调用 schema。 |

<a id="gcy"></a>
### GCY

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 转入其他规则 |
| 作用 | 转到另一 PCR 继续处理。 |
| 语法 | `GCY 规则名及可选分组` |
| 参数 / 可用值 | 指定目标 PCR；部分写法可指定目标分组。 |
| 结果 | 把后续处理交给目标规则，返回行为与 PCY 不同。 |
| 例子 | GCY Z001：转入教学示例规则 Z001。 |
| 注意 | 不要将 GCY 与需要返回继续执行的 PCY 混用。 |

<a id="nextr"></a>
### NEXTR

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 续行 |
| 作用 | 在同一规则路径内继续执行指定序号的后续行。 |
| 语法 | `NEXTR 序号` |
| 参数 / 可用值 | 序号如 A、B、1；必须存在对应的续行 SEQNO。 |
| 结果 | 继续同一判断路径的后续操作。 |
| 例子 | NEXTR A：跳到续行序号 A；ZPP2 当前后续行执行 RTE/TSDIVP、ADDWT \*。 |
| 注意 | 续行 SEQNO 和判断键 VARGT 是不同字段；不是在树下新建一个并列判断分支。 |

<a id="scond"></a>
### SCOND

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 返回真假 |
| 作用 | 向外层 schema 的 IF 返回条件。 |
| 语法 | `SCOND=T IF 或 SCOND=F IF` |
| 参数 / 可用值 | T=真；F=假；IF 表示设置 IF 条件。 |
| 结果 | 调用方进入真或假分支。 |
| 例子 | SCOND=T IF：让调用该判断 PCR 的 IF 成立。 |
| 注意 | ADDWT 不承担返回真假的作用。 |

<a id="modif"></a>
### MODIF

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE02 · 薪资 / 设置分组 |
| 作用 | 设置后续函数读取配置时使用的修饰符/分组。 |
| 语法 | `MODIF 参数` |
| 参数 / 可用值 | 常见如 1=nn（时间工资项选择分组）、2=nn（常数估值分组）、A=nn（缺勤估值分组）；nn 为配置键。 |
| 结果 | 影响后续读配置的分组，不修改人员主数据。 |
| 例子 | MODIF A=01：缺勤估值相关分组设为 01。 |
| 注意 | 相同数字在不同修饰符下不是同一组。 |

| 项目 | 速查 |
| --- | --- |

## PE01 函数字典

<a id="pit"></a>
### PIT

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE01 · 薪资 / 循环／规则调用 |
| 作用 | 逐条处理 IT 工资项并调用 PCR。 |
| 语法 | `PIT · P1=PCR · P2=处理选项 · P3=分组选项` |
| 参数 / 可用值 | P1=规则名；P2 常用空白或 GEN（通用工资项入口 \*\*\*\*）；P3 常用空白或 NOAB（通用 PCR 分组 \*）。 |
| 结果 | PCR 输出经 OT 供后续处理。 |
| 例子 | PIT · ZBOT · — · NOAB · — |
| 注意 | ZBOT 有 5000/5010/5020 专门入口，不能随意加 GEN。 |

<a id="pitab"></a>
### PITAB

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE01 · 薪资 / 整表保存／恢复／重置 |
| 作用 | 对薪资内部表进行专门的表级处理。 |
| 语法 | `PITAB · P1=操作码 · P2=表标识` |
| 参数 / 可用值 | S=保存；L=装载；D=清空/重置；A=追加；M=合并。允许的表组合由各操作的实现限定。 |
| 结果 | 改变指定工作表；不调用同名 PCR。 |
| 例子 | PITAB · S · AIT · — · —：IT→AIT；PITAB · L · AIT · — · —：AIT→IT。 |
| 注意 | PITAB D DPS 会先清空，再用 PSP 重建 DPS，并初始化 ZMODN/TAGTY/ACTIV；不等于留下空表。 |

<a id="wpbp-fn"></a>
### WPBP（函数）

| 项目 | 速查 |
| --- | --- |
| 位置 / 功能 | PE01 · 薪资 / 读取／分段 |

<a id="tables"></a>
## 内部表字段字典

**字段清单按本次实际结构展开，包含当前结构中的标准字段；屏幕可能只显示其中一部分。** 这些通常是计算内部表/结果结构，不是可以直接当同名数据库表查询的对象；当前人员、期间通常保存在外层上下文，不在每一行重复。

类型读法：CHAR(n)=n 字符；NUMC(n)=n 位数字字符；DATS(8)=日期；RAW(n)=n 字节关联号；DEC(p,s)/CURR(p,s)=总 p 位、其中 s 位小数。数值字段没有有限的“代码值清单”，应按单位、正负号和业务规则解释。

| 表 / 结构 | 存储的信息 | 字段入口 |
| --- | --- | --- |
| IT / OT / RT：PC207 | 工资项号、费率、数量、金额和关联标识；IT 输入、OT 输出、RT 结果 | [18 个字段](#tab-rt) |
| WPBP：PC205 | 人员组织信息、在职状态、工作计划和基本支付分段 | [47 个字段](#tab-wpbp) |
| CRT：PC208 → PC22Y | 按累计类型/区间保存的工资项累计量 | [9 个字段](#tab-crt) |
| VAR：HRVAR | PCR 临时变量键及 R/N/A | [6 个字段](#tab-var) |
| PSP / DPS：PC2BA → PTPSP | 逐日个人工作计划；DPS 为辅助计划表 | [13 个字段](#tab-psp) |
| ZL：PC2BF | 从时间处理送来的时间工资项 | [11 个字段](#tab-zl) |

## 核对来源与继续查法

- **本次系统依据**：BAESL_100 的 DD03L/DD04T、域固定值及上述配置表；IT/OT/VAR 声明来自 RPCFDC10、RPCFDC09_DATA99，字段结构为 PC207、PC205、PC22Y、HRVAR、PTPSP、PC2BF。关键语法对照当前标准实现及 ZA01、ZBOT、ZPP2 等实际规则。
- **查函数/操作**：PE04 输入名称，区分“函数”和“操作”，查看文档与允许参数；PE01 查看参数1—4；PE02 查看判断键与续行序号。本文未展开的少用参数以目标系统文档为准。
- **查字段和值**：SE11 显示结构 → 字段 → 数据元素 → 域；有固定值时查固定值，无固定值时查检查表/配置表及文本。带分组、国别、日期的键要一起查。
- **SAP 官方参考**：[薪资函数与操作](https://help.sap.com/docs/SUPPORT_CONTENT/erphcm/3354685492.html)用于查分类与入口；本文的 CMPER、IF、PITAB 等细节以本次系统实现核对结果为准。[时间工资项选择](https://help.sap.com/docs/HR_RENEWAL/28cb35be3518492c9ac9786bb7cf468d/0335e153a217424de10000000a174cb4.html?version=1.4.latest)说明考勤工资项向薪资传递前的来源。
