`SDSH_PROCESS_CONTROL`为搜索帮助的增强点，可通过`SE18`查看，其中包含两个BADI:

- `SDSH_SEARCH_HELP_METADATA` : 用于调整搜索帮助元数据的业务加载项
- `SDSH_SEARCH_HELP_RESULTS` : 用于调整搜索帮助结果的业务加载项

> [!Note]
>
> 该增强点无法通过`SE19`实施，报错: <u>BAdI 为内部 SAP；不允许在名空间执行</u>

## 更改搜索帮助结果

在`CL_PCA_SHLP_AUTH_CHECK`或其他实施类做隐式增强

- 调用

  ```abap
   perform change_help_results in program zhr_en_program if found using i_search_help_metadata changing c_search_help_results.
  ```

- 子例程

  ```abap
  form change_help_results using   i_search_help_metadata type shlp_descr
                           changing c_search_help_results type ddshreslts.

    check i_search_help_metadata-shlpname = 'HRPAD_PERSK'.
  ```

  ```abap
  	"动态构建搜索帮助结果结构
    data(lt_fielddescr) = i_search_help_metadata-fielddescr.
    sort lt_fielddescr by position.
    loop at lt_fielddescr into data(ls_fielddescr).
      if ls_fielddescr-offset is not initial.
        data(lv_index) = sy-tabix - 1.
        exit.
      endif.
    endloop.
  
    data: lo_struc_desc type ref to cl_abap_structdescr,
          lo_data_desc  type ref to cl_abap_datadescr,

    field-symbols: <fs_struc> type any.
  
    check lv_index is not initial.
  
    loop at lt_fielddescr into ls_fielddescr from lv_index.
      lo_data_desc ?= cl_abap_typedescr=>describe_by_name( ls_fielddescr-rollname ).
      lt_comp_tab = value #( base lt_comp_tab ( name = ls_fielddescr-fieldname type = lo_data_desc ) ).
    endloop.
  
    check lt_comp_tab is not initial.
  
    lo_struc_desc = cl_abap_structdescr=>create( lt_comp_tab ).

    assign ls_struc->* to <fs_struc>.
  
    check <fs_struc> is assigned.
  ```
