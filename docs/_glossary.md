# 术语表

##### ABAP

Advanced Business Application Programming，SAP 生态中的主要开发语言。

##### ALV

ABAP List Viewer，用于在 SAP GUI 中展示表格、列表和报表结果。

##### BAPI

Business Application Programming Interface，SAP 提供的标准业务接口。

##### CDS

Core Data Services，用于定义数据模型、视图和语义注解。

##### CPI

Cloud Platform Integration，SAP Integration Suite 中常见的云集成能力。

##### PFCG

SAP 权限角色维护事务码，常用于角色、菜单和授权对象维护。

##### RFC

Remote Function Call，SAP 系统内外远程调用函数模块的机制。

##### T-code

Transaction Code，SAP GUI 中快速进入业务或配置界面的事务码。
